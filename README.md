Expense Tracker

About the Project

This is an Expense Tracker project that Eddie and I worked on. The project helps users record their expenses and keep track of their spending. It also allows users to select different currencies and convert amounts using exchange rates.

Features

Users can add new expenses.

Users can view their expenses.

Users can delete expenses.

Users can filter expenses by category.

Users can see their total expenses.

Users can select their preferred currency.

The application uses exchange rates to convert amounts into different currencies.

## Technologies Used

HTML

CSS

Installation

First, clone the repository from GitHub.

Open the project folder in your terminal.

Run the following command to install the required packages.

npm install

 Running the Project

Open the index.html file in your browser to view the application.

Testing

Run the following command to execute the tests.

npm test
